# Panelvan Studio

Panelvan Studio is a professional web-based configurator that allows customers to visualize interior lining materials on panel vans.

## Project Goals

- Interactive SVG-based vehicle visualization
- Real material textures
- Professional user experience
- Scalable vehicle architecture
- Modern React application
