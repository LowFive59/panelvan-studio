## 1. Project Identity

Project name:

Panelvan Studio

Project type:

Interactive web-based panel van interior lining configurator.

The project is focused on visual configuration only.

Do not treat this project as:

- an e-commerce website,
- a pricing calculator,
- a quotation system,
- a shopping application.

The core purpose is to allow a user to select a vehicle, select a material, click a lining region and instantly visualize that material on the vehicle.

---

## 2. Main Product Principle

Always prioritize:

1. visual accuracy,
2. simplicity,
3. realism,
4. maintainability,
5. scalability.

The interface should feel like professional industrial configuration software.

Do not add unnecessary features.
